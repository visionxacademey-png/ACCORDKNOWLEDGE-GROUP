## Core Services

1. **Accounts** (`/services/accounts`) — Structured ledger maintenance, bank reconciliation, and financial statements.
2. **GST Registration & Returns** (`/services/gst-registration`) — Registration, GSTR-1, GSTR-3B filings, and ITC reconciliation.
3. **Income Tax Returns** (`/services/income-tax`) — Individual, business, and firm return preparation and e-filing.
4. **TDS Filing** (`/services/tds`) — Quarterly Form 24Q/26Q filing, TAN management, and Form 16/16A generation.
5. **Digital Signature** (`/services/digital-signature`) — Class 3 DSC issuance, e-tendering tokens, and MCA mapping.
6. **Project Report for Bank Finance** (`/services/project-report`) — CMA data, multi-year financial projections, and loan documentation.
7. **Partnership Deed** (`/services/partnership-deed`) — Drafting legally sound deeds complying with Section 40(b).
8. **Company & LLP Formation** (`/services/company-llp-formation`) — Private Limited & LLP incorporation with MCA.
9. **Internal Audit & Consultancy Services** (`/services/internal-audit`) — Operational review, internal control testing, and management advisory.

## Technology Stack

- **Framework:** Next.js (App Router, Static Site Generation)
- **Language:** TypeScript
- **Styling:** Tailwind CSS with custom corporate navy and warm gold palette
- **Icons:** Lucide React
- **SEO & Structured Data:** Semantic HTML5, Open Graph, Twitter Cards, JSON-LD Schema (`AccountingService`)
- **Accessibility:** WCAG compliant contrast, keyboard navigation, skip links, and `prefers-reduced-motion` support.
